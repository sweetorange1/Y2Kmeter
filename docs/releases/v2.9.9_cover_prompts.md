## 主提示词

```
Using the attached screenshot as the only style and content reference, create ONE
finished cover image for a music-software update video. Pixel-art poster, 4:3.

STYLE SOURCE
The screenshot shows my audio analyser software: near-black blue-violet background,
hot pink panel chrome, rows of module tiles with pink header bars, and one large
magenta-violet plasma orb. Keep this exact visual language — same pink, same
near-black, same tile proportions, same orb colours. Do not invent a new palette,
do not brighten the background, do not add colours that are not in the screenshot.

STRUCTURE
The canvas is 4:3. Keep every important element inside the middle 75% band of the
height; the top 12.5% and bottom 12.5% must hold only dark background and glow,
because this image will be cropped to 16:9.
Left third: the text block, left-aligned, vertically centred in the middle band.
Right two thirds: a tight, overlapping wall of module tiles taken from the
screenshot. Feature exactly these five and nothing else:
1. one loudness readout block with big cream numerals and a bar readout
2. one VU meter with a needle
3. one oscilloscope showing a flat-topped waveform
4. one stereo field radar with scattered dots
5. one large MILKDROP plasma orb, right of centre, its centre around 45% of canvas
   height — this is the single focal point of the whole image
The tiles overlap and fill the right side with no desktop visible between them.
Remove the Windows taskbar, clock, desktop icons and OS wallpaper completely.

TILE RULES
Keep the tiles' pink header bars with their small heart glyph. Header labels may be
kept exactly as in the screenshot where legible, but do not invent new labels.
Render all meters as flat pixel art: 1px dithered shading, hard aliased edges, no
anti-aliasing, no smooth gradients. The plasma orb keeps its soft glow — it is the
only element allowed smooth edges.

EXACT TEXT — VERBATIM
T01 hero title, exactly "长得可爱" then "测得很准", set as two stacked lines:
"长得可爱" on the upper line, "测得很准" on the lower line, upper-left of the text
block. This is the dominant visual structure of the cover.
T02 support line, exactly "十九个仪表，免费开源", smaller, directly under T01.
Render exactly these characters, once each, Simplified Chinese. Do not translate,
paraphrase, shorten, duplicate, or add punctuation.
No other readable text anywhere beyond the tile header labels copied from the
screenshot: no numbers, no version numbers, no line counts, no statistics, no
English words added, no kana, no watermark, no signature.
Typography: heavy blocky Chinese with thick strokes and pixel-stepped outer contours,
yet fully formed and clearly legible — not thin 8-bit dot-matrix. Cream-white fill,
hard black outline, hard magenta offset shadow. No blur, no gradient.

LIGHT AND PALETTE
Colours only from the reference: near-black blue-violet, hot pink, magenta, soft
white, and the orb's violet-cyan glow. The orb lights the surrounding tiles; every
light has a visible source. No new neon, no lens flare.

TEXTURE
1px dithered shading, visible pixel steps, no anti-aliasing, no smooth vector edges,
faint horizontal scanline overlay.

PRIORITY
Legible title first, clear orb focal point second, recognisable meters third,
decorative detail last.

AVOID
photorealism, smooth 3D render, glossy plastic, gradients outside the orb, bokeh,
lens flare, glow blur on text; Windows taskbar, clock, desktop icons, wallpaper;
any text beyond T01, T02 and the original tile labels; any number, code, file path
or statistic anywhere in the image; duplicated or mirrored tiles; more than five
featured meters; text or key objects touching the frame edge or sitting in the
top/bottom 12.5% bands; frame border, watermark, signature.
```

## 出图后

- 裁 16:9 = 保留全宽，上下各切 12.5%（1024×768 留 576）。最长的一行是 T02「十九个仪表，免费开源」，裁前确认它在安全带里。
- 任务栏如果还在，追加一句 `The bottom edge shows only dark background, no operating system taskbar`。
- **中文字糊了就走两步**：把 `EXACT TEXT` 整段删掉、加一句 `no text anywhere` 出无字版，后期用 `最像素 Zpix` 自己排。英文小字用你说的 `Press Start 2P` / `VT323`。
- **版本号不进封面**，真要标就在后期加一行小字，别让模型画。
- 这张截图本身也能直接用：右下角 Milkdrop 球那块（约 324,340 到 1080,565）裁出来接近 16:9，左下压字即可。1080 宽对 B站封面够用，Steam 页不够。
