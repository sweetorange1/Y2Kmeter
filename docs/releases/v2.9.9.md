Y2Kmeter v2.9.9  
本版汇总 v2.8.6 之后九个内部迭代的改动，2.9.0 至 2.9.8 未单独对外发版。

玩具盒 Toybox：新增全局点击互动层，OFF / CHILL / NORMAL / PARTY 四档，19 个模块各有专属反应与真实读数气泡，连击升级喷口并触发彩带雨  
调色板重写：OKLCH 配色生成器与 PalettePanel 取代原自定义主题面板，新增主题库、色票条预设与图表色谱，深浅色切换实时生效并在 Standalone / VST3 双端保存  
帧率与性能：改为 vblank 相位对齐 + 时间信用追帧的 120fps 帧调度，FPS 标签改读 GL 线程真实出帧数；动画全部帧率无关，安装包载荷从 3 万个文件压成单文件  
频谱与可视化：Spectrum 新增 Sharper 重分配模式；Stick 条状预设由 1 种扩到 4 种；Milkdrop 自定义染色、亮度与 38 个效果恢复，并接入 60fps 节流  
响度：修正 LUFS 立体声求和偏低 3.01 dB、RMS 偏低 0.691 dB、Dynamics RMS 误用算术平均三处错误；LUFS-M 改为 400ms 实时滑窗，静音 2s 重置，系统静音后读数不再冻结  
macOS：桌面采集修复内存泄漏、串行队列死锁与数据竞争，原生全屏下下拉与右键菜单定位归位；同步修复 Windows 隐藏任务栏满屏时二级弹窗被主窗口遮挡  
构建：切换到 Ninja 构建，新增 palette_test（1080 组配色全遍历）与 toy_physics_test 测试目标  
安装：Windows 运行 Y2Kmeter_Setup_2.9.9_x64.exe；macOS 打开 Y2Kmeter-2.9.9-macOS.dmg，运行其中的 pkg  

English

Y2Kmeter v2.9.9  
A roll-up of nine internal iterations since v2.8.6 — 2.9.0 through 2.9.8 were never released on their own.

Toybox: a global click-interaction layer with four levels (OFF / CHILL / NORMAL / PARTY); all 19 modules react with their own effects and live readout bubbles, and combos upgrade the emitter and trigger confetti  
Palette rewrite: an OKLCH-based palette generator and PalettePanel replace the old custom theme picker, adding a theme library, swatch presets and chart ramps; light/dark switches live and persists on both Standalone and VST3  
Frame rate & performance: 120fps scheduling with vblank phase alignment and time-credit catch-up, FPS label now counts real GL frames; all animation is frame-rate independent, and the installer payload shrinks from 30k files to a single archive  
Spectrum & visuals: new Sharper reassigned-spectrum mode; Stick bar presets expanded from 1 to 4; Milkdrop custom tint, brightness and all 38 effects restored with 60fps throttling  
Loudness: fixed LUFS stereo summing 3.01 dB low, RMS 0.691 dB low, and Dynamics RMS using an arithmetic mean; LUFS-M is now a 400ms sliding window that resets after 2s of silence, and readouts no longer freeze when the system goes quiet  
macOS: desktop capture cleared of memory leaks, serial-queue deadlocks and data races, with native full-screen menu and context-menu placement fixed; also fixed secondary popups being covered by the main window on Windows pseudo full-screen  
Build: moved to Ninja, with new palette_test (all 1080 palette combinations) and toy_physics_test targets  
Install: Windows — run Y2Kmeter_Setup_2.9.9_x64.exe; macOS — open Y2Kmeter-2.9.9-macOS.dmg and run the included pkg
